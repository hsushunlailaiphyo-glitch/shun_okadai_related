# 💰 Financial Tracker - Google Sheets Edition

**Simple, free personal finance tracker using Google Sheets. No coding, no app needed!**

Track income, expenses, investments (Shin-NISA), budget goals, and your Myanmar trip savings countdown - all in one spreadsheet.

---

## 🚀 Quick Start (5 minutes)

1. **Go to [Google Sheets](https://sheets.google.com)**
2. **Create new blank spreadsheet**
3. **Follow the setup guide** → [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)
4. **Start tracking!**

## 📤 Backup & Sharing

**Backup (Monthly):**
1. File → "Download" → "Excel (.xlsx)"
2. Save to computer
3. Keep multiple copies

**Share with others (Optional):**
1. Click "Share" (top right)
2. Add email addresses
3. Set permission: "Viewer" (read-only) or "Editor"

## 📞 Help & Support

**Google Sheets tips:**
- `Ctrl+Z` = Undo a change
- `Ctrl+/` = Search functions
- `@SheetName!Cell` = Reference another sheet

**Common questions:**
- *How do I add a chart?* → Insert → Chart (in setup guide)
- *Can I share this?* → Yes, use Share button
- *What if I lose data?* → Google auto-backs up everything
- *Can I export data?* → Yes, download as Excel anytime
